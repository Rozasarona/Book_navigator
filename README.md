# Book Navigator

Учебный MVP Telegram-бота для персонального подбора русскоязычных детских
аудиокниг. Возраст ребёнка — от 4 до 14 лет.

Система раз в неделю собирает книги, объединяет дубли, анализирует содержание,
фильтрует ограничения и готовит 5–7 карточек. Родитель проверяет и при желании
редактирует тизер. Только после одобрения карточка отправляется ребёнку.

## Конвейер

```text
Google Books / Open Library / LibriVox
                  ↓
            collector
                  ↓
 books + audio_editions + исходные ответы
                  ↓
       worker через AITUNNEL
                  ↓
 book_analyses: возраст, темы, риски, тизер
                  ↓
 профиль + ограничения + предыдущий feedback
                  ↓
     родитель → одобрение → ребёнок
```

## Источники

- Google Books — русскоязычные новинки и библиографические данные.
- Open Library — издания, ISBN, жанры, рейтинги и обложки.
- LibriVox — открытые аудиокниги, длительность и ссылки на прослушивание.
- Демонстрационный каталог — шесть книг только для офлайн-теста. В обычном
  сборе он выключен.

Google Books и Open Library не подтверждают наличие аудио. Такие книги можно
рекомендовать только с явным предупреждением. Если описания недостаточно для
проверки родительских ограничений, книга полностью исключается.

Источники настраиваются в `collector/sources.py`. Дополнительную запись с уже
поддерживаемым типом можно также добавить в таблицу `sources`. Новый формат API
оформляется отдельным reader в `collector/main.py`.

## Локальная проверка без ключей и интернета

Нужен Python 3.12 или новее. Сторонних Python-библиотек нет.

```powershell
$env:PYTHONUTF8 = '1'
$env:DATABASE_PATH = $env:TEMP\book_navigator_demo.db
python main.py pipeline --offline
python -m unittest discover -s tests -v
```

Команда проверяет весь путь: сбор → дедупликация → хранение → анализ → находки.
Для отдельной проверки профиля и рекомендаций:

```powershell
python main.py demo
```

Офлайн-эвристика нужна только для воспроизводимого теста. В рабочем режиме
используется AITUNNEL.

## Рабочий запуск

Скопируйте `.env.example` в `.env` и заполните:

```text
AITUNNEL_API_KEY=ваш ключ
AITUNNEL_BASE_URL=https://api.aitunnel.ru/v1
AITUNNEL_MODEL=auto
TELEGRAM_BOT_TOKEN=токен от BotFather
ANALYZER=aitunnel
```

Секреты нельзя добавлять в git. Затем выполните:

```powershell
python main.py pipeline
python main.py bot
```

Основные команды бота:

```text
/profile Имя | 8 | космос, приключения | страх, насилие | другое ограничение
/profiles
/recommend ID_ПРОФИЛЯ
/approve ID_РЕКОМЕНДАЦИИ
/reject ID_РЕКОМЕНДАЦИИ
/edit ID_РЕКОМЕНДАЦИИ новый тизер
/child КОД
/interests животные, юмор
```

Ребёнок может ответить: понравилось, не понравилось, уже слушал, не подходит по
содержанию или собираюсь послушать.

## Еженедельный запуск

Бот проверяет расписание сам. По умолчанию подборка готовится в воскресенье в
12:00 по Москве. Перед подбором он запускает сбор и анализ новых книг.

```text
WEEKLY_WEEKDAY=6
WEEKLY_HOUR_MSK=12
```

Повторный запуск в ту же неделю защищён записью в `runs`.

## Coolify

1. Подключите GitHub-репозиторий и выберите сборку по `Dockerfile`.
2. Добавьте переменные из `.env.example`.
3. Подключите постоянный volume к `/app/data`.
4. Оставьте команду контейнера `python main.py bot`.

Без постоянного volume база SQLite будет потеряна при пересоздании контейнера.

## Данные

- `profiles` — возраст 4–14 лет, интересы и ограничения;
- `books` — нормализованное произведение;
- `audio_editions` — озвучки, доступность, ссылки и исходный JSON;
- `reviews` — подготовлено для оценок и отзывов;
- `book_analyses` — вывод модели, флаги, уверенность, стоимость и request ID;
- `recommendations` — черновик, одобрение и отправка;
- `feedback` — реакция ребёнка;
- `runs` — журнал сборов, анализа и недельных запусков.

Полезные аналитические запросы находятся в `db/queries.sql`.

## Ограничения MVP

- Коммерческие каталоги Литрес, Яндекс Книги и Строки не подключены без
  официального доступа. Защита, авторизация и платный контент не обходятся.
- Полнота русскоязычных аудиокниг в бесплатных API ограничена.
- Анализ безопасности основан на доступных аннотациях и метаданных, а не на
  полном тексте книги. Недостаток данных приводит к исключению книги.
- SQLite подходит для учебного MVP и одного процесса. Для масштабирования нужно
  перейти на PostgreSQL и очередь фоновых задач.
